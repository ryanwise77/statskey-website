TX-A22 will be rebuilt from basic assembly, not patched from broken renders.

This page is the working program for the acoustic-first hybrid. The previous TX-A22 option was removed because it mixed incompatible geometry: imported Taylor body fragments, custom necks, imported Strat fragments, and un-clipped internal parts. The new process starts with one coherent assembly basis, then adds capability only after the base instrument looks physically correct.

Status: TX-A22 is not a live build option right now. It is a staged engineering program. The public option list contains only the currently valid eight viewers.

Assembly Stack

Rules Going Forward

One Chassis

Use one body/neck coordinate system at a time. No stacking imported necks over generated necks. No duplicated body shells.

Geometry Before Features

Body silhouette, neck joint, headstock, bridge and string path must be visually correct before pickups or electronics are added.

No Top Routing For Magnetics

Magnetic capability must mount via soundhole, pickguard/fingerboard extension, or structural rail that does not cut the acoustic top.

Publish Only Stable Stages

Broken transitional CAD stays private. Public pages show either valid options or clearly labeled engineering program pages.
