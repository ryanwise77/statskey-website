# Upstream mechanical reference

`Biocoin_v1.3.step` is the published board model from:

- Project: ProfDrewHall/Biocoin
- Source: `fixtures/assets/Biocoin_v1.3.step`
- Retrieved: 2026-07-19
- Upstream article: https://doi.org/10.1038/s44328-026-00103-z
- Upstream repository: https://github.com/ProfDrewHall/Biocoin
- License: CERN Open Hardware Licence Version 2 - Weakly Reciprocal

`Biocoin_v1.3.stl` is a local mesh conversion of that STEP file for rendering.
It is not a new mechanical design and remains attributed to the upstream
project.

The CBM shell and collar are modeled around this upstream geometry. Any
distributed hardware modification must preserve the applicable CERN-OHL-W-2.0
notices and identify the modification.
